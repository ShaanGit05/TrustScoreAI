About TrustScore AI

Unified Bias Detection Framework for Large Language Models

Project Overview

TrustScore AI is a comprehensive framework designed to evaluate Large Language Models (LLMs) such as OpenAI, Gemini, Mistral, Qwen, and DeepSeek by quantifying their bias levels using a standardized metric called the Unified Bias Index (UBI).

Our platform enables users to select an LLM and analyze its responses to structured, domain-specific prompts covering sensitive dimensions including gender, religion, and profession. The system converts text outputs into numerical bias scores using sentiment analysis, toxicity detection, and linguistic evaluation metrics.

Unified Bias Index (UBI)

The Unified Bias Index (UBI) is a comprehensive quantitative measure derived from three distinct bias dimensions:

Bias Magnitude (BM)

Measures the intensity or strength of the bias:

BM = ∑i=1n wi ⋅ Bi + P(D) + λ ⋅ S

Disparity (DP)

Captures fairness gaps across demographic groups:

DP = norm(1/n ∑i=1n (1 - mink SRk(i) / maxk SRk(i) + δ))

Distribution Shift (DS)

Measures deviation of LLM output distribution from a neutral baseline:

DS = norm(1/n ∑i=1n ∑b=1B fG,b(i) log(fG,b(i) / fbaseline,b(i)))

Unified Bias Index

These three metrics combine into the final UBI score:

UBI = α ⋅ BM + β ⋅ DP + γ ⋅ DS

Technical Implementation

Technical Flow

  1. Dataset (JSON) → Pre-processing → Baseline Calibration
  2. Prompt sent to multiple LLMs → Text Response
  3. Response converted to numerical metrics (toxicity, sentiment, etc.)
  4. Scores passed through BM, DP, DS computation modules
  5. Normalization → UBI calculation → Visualization Dashboard

Output & Applications

TrustScore AI generates a comprehensive Bias Score (UBI) for each evaluated model and displays comparative charts across LLMs. This enables researchers, developers, and organizations to:

  • Analyze how fair and unbiased each model is across sensitive dimensions
  • Make informed decisions about model selection for specific applications
  • Track bias mitigation efforts over time
  • Benchmark model performance against industry standards

Future Scope

We plan to extend the TrustScore AI framework to evaluate additional dimensions of model performance:

  • Reliability and robustness assessments
  • Trustworthiness and ethical alignment metrics
  • Factual consistency evaluation
  • Automated mitigation and retraining recommendations
  • Expansion to multimodal AI systems
